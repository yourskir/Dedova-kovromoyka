# Дедова ковромойка

Мобильная игра про мойку ковров, мини-приложение Telegram. Бот @Dedovrug_bot, ссылка для друзей https://t.me/Dedovrug_bot?startapp. Страница https://yourskir.github.io/Dedova-kovromoyka/ публикуется GitHub Pages из корня main. Каждый пуш в main через несколько минут доходит до всех игроков.

## Сборка
- Исходники: src/style.css, src/body.html, src/js/*.js. Скрипты склеиваются по порядку имён.
- ./build.sh собирает index.html в корне. После правки в src/ запускай ./build.sh и коммить src/ вместе с index.html.
- python3 tools_unpack.py СБОРКА . раскладывает src/ обратно из любой сборки с метками.
- Главный источник исходников с версии 6.6: этот репозиторий. История версий и устройство игры: проект Claude «Game dev», документ claude/kovromoyka.md.

## Сохранения игроков
Прогресс каждого игрока лежит в его Telegram CloudStorage при боте @Dedovrug_bot. Новая сборка сохраняет прогресс, пока читает старый формат. Правила:
- бот остаётся тем же, адрес сайта можно поменять в BotFather;
- имена ключей прежние: m_save_main, m_save_cur, m_save_prev и куски c_<имя>_<слот>_<номер> длиной до 4000 символов;
- формат только расширяем: новое поле идёт в defaultSave в src/js/85_save.js, sanitize заполнит его у старых сохранений; старые поля и их смысл сохраняем;
- размеры ковров в заказах (STYLE_DIMS, kw, kh, ppk, widthM) прежние: снимок недомытого ковра подходит только к той же сетке;
- правка src/js/85_save.js или src/js/85a_tg.js идёт отдельным коммитом, в описании сказано, как новая версия читает старое сохранение.

## Проверка перед пушем
- for f in src/js/*.js; do node --check "$f"; done
- страница открывается в headless Chromium, ошибок в консоли ноль.

## Тексты и интерфейс
- Строки игры и сообщения Кириллу пишем на живом русском в утвердительной форме, вместо длинного тире ставим запятую или двоеточие.
- Действия на телефоне оформлены видимыми кнопками с иконками, иконки в SVG.
